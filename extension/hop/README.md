# Hop

登録したページをワンクリックで開く Chrome 拡張。
開いた後のクリック・入力を自動実行できる。

- 例: Firestore の特定コレクションを、フィルタ済みで開く
- 操作は録画でも手書きでも登録できる

## 入れ方

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」で、このディレクトリを選ぶ
4. ツールバーのパズルアイコンから Hop をピン留め

- 更新したら `chrome://extensions` の Hop の再読み込みボタンを押す
- ショートカット: `Alt+Shift+K` で一覧を開く
  - 変更は `chrome://extensions/shortcuts`

## 使い方

### 開く

- アイコン (または `Alt+Shift+K`) で一覧を出す
- 文字を打つと絞り込み
  - 対象: 名前、グループ名、URL
- `↑` `↓` で選び、`Enter` で開く
  - クリックでも開く
- `auto` の付いた項目は、開いた後に自動実行が走る

### 登録する

1. 登録したいページを開く
2. 一覧の `+` を押す
   - 名前と URL は今のページで埋まる
3. 必要なら項目を直して「保存」

| 項目 | 内容 |
| --- | --- |
| 名前 | 一覧に出る名前 |
| グループ | 一覧の見出し。空なら「その他」にまとまる |
| URL | 開くページ |
| 開き方 | 新しいタブ / 現在のタブ |
| 自動実行 | 開いた後の操作。下の「自動実行」を参照 |

### 直す・消す

- 一覧の行の `✎` で編集画面へ
- 削除は編集画面の「削除」を 2 回押す

### グループ

- 編集画面の「グループ」に名前を入れると、一覧で見出しの下にまとまる
  - 既存のグループ名は候補に出る
- 見出しをクリックすると畳む / 開く
  - 畳んだ状態は次回も残る
  - 検索中は畳みを無視し、一致したものを全部出す

## 自動実行

### 録画する (おすすめ)

1. 編集画面で「● 録画」を押す
   - 今のタブで URL を開き直して、録画が始まる
   - アイコンに `REC` が付く
2. ページ上で、自動化したい操作をする
   - 右上のバーに記録した手数が出る
3. バーの「保存」を押す
   - 「取消」なら何も保存しない
4. アイコンを押すと、録画結果の入った編集画面が開く
   - 必要なら手で直して「保存」

記録されるもの:

- クリック
  - 入力欄・セレクトボックスへのクリックは記録しない (入力で記録する)
- 入力欄の文字
  - 1 打鍵ずつではなく、次の操作の直前の最終値を 1 手として記録
- セレクトボックスの選択
- `Enter` / `Escape` キー

### コマンド

1 行 1 コマンド。上から順に実行する。

| コマンド | 動き |
| --- | --- |
| `wait 1000` | 1000 ミリ秒待つ |
| `wait <要素>` | 要素が出るまで待つ |
| `click <要素>` | クリック |
| `type <要素> \| <文字>` | 入力欄・セレクトボックスに値を入れる |
| `press <キー>` | キーを送る (`Enter`、`Escape` など) |

- 空行と `#` で始まる行は無視
- `click` と `type` は要素が出るまで最大 10 秒待つ
  - 画面の表示待ちに `wait` を書く必要はほぼ無い
- `press` は直前に `click` / `type` した要素へ送る
- 途中で失敗すると、ページ右下に何行目で止まったかが出る

### 要素の指定

2 通り。

- **CSS セレクタ**: DevTools で要素を右クリック => Copy => Copy selector
  - 例: `#search`、`input[name="q"]`、`button[aria-label="Filter"]`
- **表示文字**: `text:` の後に、画面に出ている文字の一部
  - 例: `text:フィルタを追加`
  - 一致する要素のうち、最も内側で、見えているものの最初の 1 つ

壊れにくい指定:

- `aria-label`、`name`、`placeholder`、`data-testid` などの属性
- ボタンやリンクの表示文字
- 数字入りの id (`mat-input-3` など) は避ける
  - 開くたびに番号が変わることがある
  - 録画もこの順で指定を選び、数字入りの id は使わない

### 例: Firestore をフィルタ済みで開く

まず `+` で登録して開き直し、
フィルタが URL に残るか確かめる。
残るなら自動実行は要らない。

残らない場合の例 (コンソールの表示文字に合わせて直す):

```
click text:フィルタを追加
type input[aria-label="フィールドのパス"] | status
type input[aria-label="値"] | active
press Enter
```

- 録画で作って、要素の指定だけ手で直すのが早い

### できないこと

- ページをまたぐ操作
  - 自動実行は最初に開いたページの中だけで動く
  - 途中で画面全体が読み込み直されると、そこで止まる
  - 録画中に読み込み直しが起きると、バーに警告が出る
- iframe の中の要素
- 改行を含む入力

## バックアップ・並べ替え

- 一覧の下の「JSON で一括編集 / バックアップ」
  - 「コピー」でクリップボードへ
  - 貼り付けて「保存」で復元
  - 配列の順番を入れ替えると、一覧の並びが変わる
- データはこの Chrome の中だけに保存 (`chrome.storage.local`)
  - 別の PC へは JSON をコピーして持っていく

JSON の 1 件:

```json
{
  "name": "prod users (active)",
  "group": "Firestore",
  "url": "https://console.firebase.google.com/project/xxx/firestore/databases/-default-/data",
  "target": "new",
  "steps": "click text:フィルタを追加\npress Enter"
}
```

- 必須: `name`、`url`
- `group`、`target`、`steps`、`id` は省略可

## 開発

- テスト: `node --test` (このディレクトリで)
- アイコン: `icons/icon.svg` を直して PNG を作り直す

```sh
for s in 16 32 48 128; do rsvg-convert -w $s -h $s icons/icon.svg -o icons/icon$s.png; done
```

| ファイル | 役割 |
| --- | --- |
| `popup.*` | 一覧・編集画面 |
| `background.js` | 開く・自動実行の注入・録画の状態管理 |
| `steps.js` | 自動実行のコマンドの解析 |
| `actions.js` | 登録データの保存・グループ分け・検証 |
| `pagekit.js` | ページ内で要素を探す・録画時の指定を選ぶ |
| `runner.js` | ページ内で自動実行する |
| `recorder.js` | ページ内で操作を記録する |
